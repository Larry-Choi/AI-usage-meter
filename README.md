# AI Usage Meter (작업표시줄 AI 토큰 사용량 & 포켓몬 위젯)

Windows 작업표시줄 및 오버레이에서 복수의 로컬 AI 도구(**Google Antigravity**, **Claude Desktop / Code**, **Cursor IDE**, **Codex CLI**)의 5시간 세션 쿼터·주간 사용량·리셋 카운트다운을 무인증으로 실시간 모니터링하는 데스크톱 위젯입니다.

![스크린샷](img/01.png)

---

## ✨ 주요 특징 및 고도화 기능

1. **로컬 AI 도구 무인증 자동 연동 (Zero-Auth)**
   - **Google Antigravity**: 실행 중인 `language_server`의 Connect-RPC 및 `agy` CLI 세션을 자동 감지하여 실시간 모델별 쿼터와 주간 한도를 조회합니다.
   - **Claude Desktop / Claude Code**: CLI 자격증명 및 Windows Desktop 앱(일반 설치 / Microsoft Store 패키지 데이터 경로 포함)의 로컬 세션을 자동 탐색해 5시간·주간 쿼터를 실시간 표시합니다.
   - **Cursor IDE**: 로컬 SQLite(`state.vscdb`) 세션을 안전하게 읽어 Cursor 월간/주간 Fast Request 사용률과 리셋 일정을 실시간 조회합니다.
   - **Codex CLI**: 로컬 Codex 세션 및 런타임과 연동하여 주간 한도를 모니터링합니다.

2. **⚡ 파트너 포켓몬 도감 & 상태 반응형 아바타**
   - 각 AI 계정마다 **13종의 도트 애니메이션 포켓몬**(피카츄, 리자몽, 파이리, 꼬부기, 어니부기, 이상해씨, 루카리오, 팬텀, 잠만보, 뮤츠, 이브이, 야돈, 잉어킹)을 파트너로 지정할 수 있습니다.
   - 팝업 카드의 포켓몬 아이콘 또는 `[⚡ 변경]` 배지를 클릭하면 **포켓몬 도감 모달**이 열려 원하는 캐릭터로 즉시 변경 및 영구 저장됩니다.
   - 쿼터가 100% 소진되면 포켓몬이 기절(흑백/회전) 상태로 전환되어 직관적으로 한도 소진을 알려줍니다.

3. **콤팩트 위젯 바 (가로 최대 3개 제한 + `+N` 더보기 배지)**
   - 작업표시줄 공간을 과도하게 차지하지 않도록 위젯 바에는 **최상위 3개 계정만 콤팩트하게 표시**됩니다.
   - 활성화된 계정이 4개 이상일 경우 우측 끝에 `+N` 배지가 표시되며, 클릭 시 전체 계정을 볼 수 있는 상세 팝업이 열립니다.
   - `[계정 관리]` 탭에서 `▲ / ▼` 버튼으로 위젯 바에 노출할 우선순위 3개 계정을 자유롭게 배치할 수 있습니다.

4. **모던 글래스모피즘 UI & 4종 테마**
   - 다크 아크릴 그라데이션과 네온 글로우 프로그레스 바가 적용된 세련된 카드 디자인.
   - **4가지 위젯 바 테마(`1a` 바 게이지, `1b` 세그먼트, `1c` 이중 링, `1d` 초압축 스택)** 및 컬러/모노크롬 아이콘 전환 지원.
   - **배치 모드**: Windows 11에서도 커서 로딩이나 깜빡임 없이 부드럽게 동작하는 **플로팅(작업표시줄 바로 위)** 모드 및 **도킹** 모드 지원.

5. **세련된 네이티브 무콘솔 런처 (`AI Usage Meter.exe`)**
   - 검은색 CMD 창이 번쩍이는 투박한 배치(`.bat`) 파일 대신, `.NET` 네이티브 GUI 서브시스템(`/target:winexe`)으로 컴파일된 전용 **`AI Usage Meter.exe`** 런처를 생성합니다.
   - 실행 시 기존 잔류 프로세스나 싱글톤 락(`SingletonLock`) 충돌을 스스로 정리하고 백그라운드에서 즉시 위젯을 띄웁니다.

## 🚀 설치 및 실행 방법

### 1. 의존성 설치 및 빌드
```bash
# 1) 패키지 설치
npm install

# 2) 네이티브 런처(AI Usage Meter.exe, TaskbarDock.exe) + TypeScript + Vite 전체 빌드
npm run build
```

### 2. 실행
빌드가 완료되면 프로젝트 루트에 **`AI Usage Meter.exe`** 가 생성됩니다.
- **`AI Usage Meter.exe`** 를 더블클릭하거나 바탕화면 바로가기에 등록하여 콘솔 창 없이 바로 실행하세요.
- 개발 중 터미널에서 실행하려면 아래 명령어를 사용할 수 있습니다:
  ```bash
  npm start
  ```

### 3. 단독 배포 패키지 생성 (선택 사항)
```bash
# Windows 무설치 폴더형 패키지 (dist-release/win-unpacked)
npm run dist

# 배포용 ZIP 아카이브 생성
npm run dist:zip
```

## 🔒 개인정보 및 보안 설계
- 모든 설정과 계정 목록은 레포지토리 내부가 아닌 각 사용자의 OS 로컬 앱 데이터 경로(`%APPDATA%\ai-usage-taskbar-widget`)에만 저장됩니다.
- 소스 코드 내에 어떠한 개인 이메일, 토큰, 계정 ID, 로컬 절대경로도 하드코딩되어 있지 않으며, 모든 인증 정보는 메모리 내에서만 일시적으로 사용됩니다.
